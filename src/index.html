// editorial note

Source-preserving enrichment.

The original code is shown verbatim. Added constraints are explicitly labelled as suggested practice assumptions. Exact LeetCode matches are separated from related practice suggestions. Complexity strings remain “as documented” so repository quirks are not silently rewritten.

License note: no license metadata was available during this build. Attribution and source links are therefore kept prominent.

Built to study, not to shortcut.

What dsa-prep adds

  • One searchable interface for every repository solution.
  • Topic, subtopic, level, status, pattern, notes, and LeetCode-match filters.
  • Inferred practice constraints, intuition, edge cases, common pitfalls, and per-question pseudocode.
  • Exact-vs-related LeetCode labelling instead of pretending every sheet problem has a one-to-one equivalent.
  • Private browser-local progress, bookmarks, confidence, notes, import, and export.
