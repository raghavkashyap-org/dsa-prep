# dsa-prep

A self-contained DSA learning dashboard built from the **raghavkashyap-org/dsa-prep** problem set.

## Coverage

- **369** C++ questions and solutions
- **16** topic tracks and **52** subtopics
- **237** exact LeetCode matches
- **132** related LeetCode practice suggestions
- Problem statements, approaches, complexity analysis, inferred practice constraints, edge cases, pitfalls, pseudocode, and original C++ source

### Topics

Arrays, Binary Search, Strings, Linked Lists, Recursion, Bit Manipulation, Stacks and Queues, Sliding Window, Heaps, Greedy Algorithms, Binary Trees, Binary Search Trees, Graphs, Dynamic Programming, Tries, and Hard String Problems.

### Patterns covered

Binary Search, Two Pointers, Sliding Window, Hashing, Sorting, Recursion, Backtracking, Dynamic Programming, Greedy, Bit Manipulation, Linked-List Pointers, Stack/Queue, Monotonic Stack, Heap/Priority Queue, Tree Traversal, BFS, DFS, Topological Sorting, Shortest Paths, Disjoint Set Union, and Tries.

## Features

- Search and filter by topic, subtopic, difficulty, pattern, status, and LeetCode match
- Toggle between language-neutral pseudocode and the exact C++ solution
- Solved tracking, bookmarks, confidence levels, and personal notes
- Per-topic progress dashboard, random problem, and continue-learning controls
- Progress import/export with browser-local storage
- Responsive dark, light, and cyber themes
- Fully self-contained—no account, dependencies, backend, or build step

## Run locally

Download `dsa-prep.html` and open it in any modern browser.
